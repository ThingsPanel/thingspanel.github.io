# Projects & Dashboards

## Create a project

1. Go to **Visualization → Dashboard**.
2. Click **New Project**.
3. Enter name and optional description.
4. Click **Create**.

![New project](./images/thingsvis/02-new-project-modal.png)

## Open a project

Click a project card to open its dashboard list.

![Dashboard list](./images/thingsvis/03-dashboard-list.png)

## Create a dashboard

1. Click **New Dashboard**.
2. Enter name and choose canvas mode: **Fixed**, **Grid**, or **Infinite**.
3. Click **Create**.

![New dashboard](./images/thingsvis/04-new-dashboard-modal.png)

## Dashboard actions

| Action | Description |
|--------|-------------|
| Thumbnail click | Full-screen preview (`/tv-preview`) |
| Edit | Open ThingsVis editor |
| Menu icon | Add to sidebar navigation |
| Home icon | Set as login homepage |
| Delete | Remove dashboard |

Only one dashboard per tenant can be marked as homepage (red **首** badge).
