# 看板（ThingsVis）

租户管理员的看板操作与系统管理员一致，数据范围限定在 **本租户** 内。请按以下顺序阅读：

1. [看板概述](../../system-admin-operation-manual/visualization/thingsvis-overview.md)
2. [项目与仪表盘](../../system-admin-operation-manual/visualization/thingsvis-project.md)
3. [编辑器操作](../../system-admin-operation-manual/visualization/thingsvis-editor.md)
4. [数据配置](../../system-admin-operation-manual/visualization/thingsvis-data.md)
5. [进阶配置](../../system-admin-operation-manual/visualization/thingsvis-advanced.md)
6. [组件说明](../../system-admin-operation-manual/visualization/thingsvis-widgets.md)

:::info 权限差异
租户管理员只能看到本租户的设备、项目和仪表盘。系统级统计（如全平台设备总数）仅超管空间可见。
:::
