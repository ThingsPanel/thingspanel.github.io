# 通知记录

打开**告警 → 通知记录**查看当前租户的通知。页面把“新投递”和“旧历史”分开显示；两类记录的状态含义不同，不会合并成同一个列表。

## 新投递

新记录显示通知请求及逐目标投递状态。根据服务商能力，状态可能为已排队、已受理、失败、未知，或由送达回执进一步更新。

- **服务商已受理**表示服务商接受了提交，不证明收件人已经收到或读过。
- 只有可信的服务商回执才能将状态显示为**已送达**或**送达失败**。
- **已受理但无回执**表示服务商接受了请求，但该渠道不报告送达状态。
- **结果未知**表示当前无法确认处理结果，不要盲目再次提交同一通知。

## 旧历史

旧记录仍在独立区域提供查看。原有 `SUCCESS` 和 `FAILURE` 表示旧系统记录的处理状态，不能解释成收件人实际收到消息的证明。

发送新通知时，先配置[通知策略](./Notification_group.md)，并在对应告警规则中选择该策略。保存或校验策略不会新建投递记录或发送消息；只有明确执行“发送测试”才会发起测试投递。
