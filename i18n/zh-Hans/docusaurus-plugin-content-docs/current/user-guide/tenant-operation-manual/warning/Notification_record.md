# 通知记录

打开**告警 → 通知记录**，查看当前租户每次通知和各收件目标的处理结果。

## 发送记录

| 状态 | 大白话说明 |
|---|---|
| 已排队 | 通知已保存，等待发送。 |
| 服务商已受理 | 服务商收下请求，还不能确认收件人已收到。 |
| 已送达 / 送达失败 | 服务商提供了可信的最终回执。 |
| 已受理但无回执 | 请求已受理，但该渠道不报告最终送达结果。 |
| 结果未知 | 无法确认发送结果，不要盲目重复发送。 |

打开记录详情，核对通知目标、尝试次数、时间和错误原因。邮件可能进入垃圾邮件；平台显示受理时，还应检查实际邮箱。

## 历史记录

在**历史记录**中查询保存的通知活动。记录中的成功或失败描述平台当时的处理结果，不能当作收件人已经收到的证明。

告警使用[通知策略](./Notification_group.md)：单独选择的策略优先，否则使用租户默认策略。保存或校验配置不会发送消息；触发告警或明确执行发送测试才会产生发送任务。
