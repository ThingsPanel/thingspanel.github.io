# 组件说明

ThingsVis 编辑器左侧 **组件库** 提供各类可视化组件。用法与 [DataV 组件指南](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/configuration-items) 类似：从组件库拖拽到画布，在右侧 **属性** 面板配置样式与数据。

:::info 阅读方式
- 通用操作（拖拽、保存、字段绑定）见 [编辑器操作](./thingsvis-editor.md)、[数据配置](./thingsvis-data.md)。
- 下方按组件库分类列出全部组件；**已文档化** 的可点击查看详细配置项说明，其余标记为待补充。
:::

## 属性面板说明

选中画布上的组件后，右侧属性面板按分组展示配置项，常见分组如下：

| 分组 | 说明 |
|------|------|
| **基础信息 / 其他外观** | 尺寸、位置、背景、内边距、不透明度等通用样式 |
| **内容** | 组件主要显示内容，支持静态 / 字段 / 表达式 |
| **样式 / 字体 / 排版** | 颜色、字号、对齐等视觉配置 |
| **数据** | 部分组件有独立数据项，详细绑定见 [字段选择器](./thingsvis-data.md#字段选择器数据绑定弹窗) |

各组件的非通用属性，请参见对应组件文档。
