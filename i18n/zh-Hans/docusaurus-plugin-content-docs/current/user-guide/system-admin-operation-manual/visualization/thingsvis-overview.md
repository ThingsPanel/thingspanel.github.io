# 看板概述

ThingsPanel 的「看板」基于 **ThingsVis** 可视化引擎，用于搭建工业监控大屏、设备看板和运营仪表盘。

## 核心概念

| 概念 | 说明 |
|------|------|
| **项目** | 看板的容器，一个项目可包含多个仪表盘 |
| **仪表盘** | 具体的大屏页面，包含画布、组件和数据绑定 |
| **组件** | 图表、数值卡、工业图元等可视化积木 |

## 访问环境

本教程示例环境：

- 地址：`http://192.168.20.102:5002`
- 账号：`test@test.cn` / `123456`

## 进入看板

1. 打开 ThingsPanel 并登录。

![登录页](./images/thingsvis/00-login.png)

2. 在左侧菜单依次点击 **可视化 → 看板**。

![项目列表](./images/thingsvis/01-project-list.png)

页面展示当前租户下的所有可视化项目。每个项目卡片显示项目名称、描述、仪表盘数量和更新时间。

## 与其他模块的关系

- **设备接入**：看板中的设备数据来自已接入的设备及其物模型字段。
- **首页**：可将某个仪表盘设为登录后的默认首页。
- **系统菜单**：可将仪表盘挂到侧边栏，方便运营人员直达。
